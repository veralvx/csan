# Security Policy

## Supported Versions

Security updates and patches are exclusively applied to the latest `main` branch and the most recent Git release tag.

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.** To report a vulnerability or privilege escalation vector, please use the [Private Vulnerability Reporting](https://github.com/veralvx/csan/security/advisories/new) feature in this repository.
